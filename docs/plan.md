# 微动放大镜 · 开发计划

对应 02-后备点子 #2（2026-10-29 选定）。四项硬要求同 00/24。

## 产品定义

把视频里肉眼难察觉的微小运动放大到看得见：音箱外壳振动、吊灯晃动、植物呼吸、桌面微震。

## 核心引擎（简化欧拉运动放大——真实算法，不是运动热图冒充）

1. 抽帧：`<video>` seek 抽帧，限制 ≤15 秒、缩放到宽 ≤360px（逐帧 RGBA → luma 浮点数组），帧率从视频元数据读取。
2. 时域处理（逐像素，实时性不要求，离线处理 + 进度条）：
   - 空间：单层金字塔下采样（×0.5 到 ≤180px 宽）以降低噪声与计算量；
   - 时域：一阶 IIR 低通（alpha 依频带）+ 慢速低通相减得带通分量（近似带通滤波）；
   - 放大：带通分量 × 用户增益（默认 12，范围 2–50）；
   - 重建：放大分量加回原帧（上采样后逐像素加到 RGB）。
3. 导出：处理后的帧序列经 canvas 逐帧 + `MediaRecorder` 重编码 WebM；处理进度条真实反映已处理帧数/总帧数。
4. 诚实边界：单层金字塔简化版对大幅运动会产生伪影（界面注明"适合固定机位的微小运动"）；输出仅 WebM；增益过高会失真——滑块实时预览某一帧让用户自己选。

## UI（大众审美 + 零学习成本）

浅色主题；三步：导入视频 → 选要放大的快慢（滑块：慢=吊灯摇晃，快=音箱振动）+ 增益滑块 → 处理并导出。预览用"原视频 vs 放大后"并排对比。
